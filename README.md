# Tennis-Comeback 28.12.

Persönlicher Trainingsplan vom 22.11. bis zum Tennis-Comeback am 28.12.: Tagesansicht mit Abhaken, Schmerzwert, Sätzen und Fortschritt.

- `index.html` ist die Quelle.
- `docs/index.html` ist die Version für GitHub Pages. Nach jeder Änderung an `index.html` neu erzeugen:

```
python build-pages.py
```

Einträge werden im Browser des jeweiligen Geräts gespeichert (localStorage).
